TMS-AppsLauncher ポータブル ZIP 版

このフォルダを任意の場所へ展開し、TmsAppLauncher.exe を起動してください。
インストール、UAC 昇格、スタートメニュー登録は行いません。

■ 注意（必ずお読みください）

- portable-mode.json は削除しないでください。
  削除するとインストーラ版として動作し、設定が %APPDATA% へ保存されます。
- Windows の SmartScreen 等で警告が出ることがあります。
  「詳細情報」から実行できる場合は、その操作で問題ありません。
- v1.8.0 時点ではコード署名はありません。

■ データの保存場所

アプリが作る設定・ログ・キャッシュは、すべて TmsAppLauncher.exe と同じ階層の
data フォルダへ保存します。C ドライブ上でも USB 上でも同じです。

顧客端末の %APPDATA% やレジストリへ、アプリ自身の永続データは書きません。
data フォルダは初回起動時に作成されます。配布 ZIP には含まれません。

■ 更新手順

1. TMS-AppsLauncher を終了する
2. 公式ページから新しいポータブル ZIP を入手する
3. 新しいフォルダへ展開する（実行中のフォルダへ上書きしない）
4. 旧版の data フォルダを新版へコピーする
5. 新版を起動して設定を確認する
6. 問題がなければ旧版フォルダを削除する

自動ダウンロードや自動インストールは行いません。
更新がある場合は、アプリが公式ページへ案内します。
